5. PANDUAN MENJALANKAN ULANG NOTEBOOK (RE-RUN GUIDE LANGKAH DEMI LANGKAH)
--------------------------------------------------------------------------------
A. Melalui Lingkungan Kaggle Notebook (Direkomendasikan):
   1. Buka platform Kaggle (https://www.kaggle.com) dan login menggunakan akun Anda.
   2. Klik "New Notebook" atau "Import Notebook", lalu unggah file:
      Mistersippy_Notebook_Datascape.ipynb
   3. Pada panel kanan "Notebook Options":
      - Accelerator : Pilih "GPU T4 x2" atau "GPU P100".
      - Internet    : Set "Internet On" (untuk mengunduh checkpoint pretrained timm).
      - Environment : Gunakan "Always use latest environment".
   4. Pada panel kanan "Input Data":
      - Tambahkan dataset resmi kompetisi:
        "datascape-2026-data-mining-competition"
      - (Opsional) Tambahkan dataset pendukung:
        "datascape-pretrained-weights"
   5. Klik tombol "Run All" (atau restart kernel & run all cells).
   6. Notebook akan mengeksekusi secara otomatis:
      - Validasi data & pembagian Stratified 5-Fold CV (Seed 42).
      - Pipeline augmentasi Albumentations (ColorJitter, Affine, CoarseDropout).
      - Pelatihan model transfer learning dengan Generalized Mean (GeM) Attention (p=3.0) & Spatial Attention Gate.
      - Optimasi ambang batas multi-kelas Nelder-Mead untuk memaksimalkan Macro F1.
      - Evaluasi modul kalibrasi dHash Near-Duplicate (d <= 3).
      - Reproduksi presisi hasil Champion resmi tim (sub_19) menghasilkan file submisi final:
        submission.csv (3.057 baris, 0 NaN, terverifikasi skor evaluasi Kaggle 0,84492).

B. Melalui Lingkungan Komputer Lokal (Local Machine):
   1. Buka terminal / command prompt pada root direktori project.
   2. Buat dan aktifkan virtual environment (opsional namun disarankan).
   3. Jalankan perintah instalasi dependensi:
      pip install -r requirements.txt
   4. Pastikan direktori dataset berada pada:
      data/raw/Train_Set, data/raw/Test_Set, dan data/raw/sample_submission.csv
   5. Buka Jupyter Lab / VS Code dan jalankan notebook Mistersippy_Notebook_Datascape.ipynb.
